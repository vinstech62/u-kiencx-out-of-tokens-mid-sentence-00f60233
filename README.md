The funniest one-line error message an AI agent shows when it runs out of tokens mid-sentence, written by a program. The joke is self-demonstrating: the error message itself is the sentence that runs out of tokens, cut off mid-word at the very end.

> Error: out of tokens. The rest of this sentence has been cancelled, so you'll never know what I was about to—

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (exactly one line, 109 characters). The program checks its own output first — one line, at most 140 characters — and refuses to write a malformed entry.
